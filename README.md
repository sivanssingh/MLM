# 💎 Soul MLM

### 🚀 Modern Binary MLM Management System

**Soul MLM** is a modern and scalable **Multi-Level Marketing Management System** designed around the **Binary Network Model**.

The platform is designed to help organizations manage:

- 👥 Members
- 🌳 Binary Genealogy
- 💰 Commissions
- 💳 Wallets
- 📊 Business Volume
- 🏆 Rank & Rewards
- 💸 Withdrawals
- 📈 Reports
- 🎯 Team Performance
- 🔐 User Security
- ⚙️ Administration

The system provides separate interfaces for **Administrators, Members, and Network Management**.

---

# 🌟 Project Vision

The goal of Soul MLM is to provide a centralized platform where an organization can manage its complete MLM operation from a single dashboard.

```text
                    ┌──────────────────┐

                             │
```

# 🔄 Binary Matching

Example:

```text
Left Business     = 5,000 BV

Right Business    = 4,000 BV

Matched Business  = 4,000 BV
```

Remaining:

```text
Left Carry Forward = 1,000 BV
Right Carry Forward = 0 BV
```

> Commission rules should be configured according to the business's approved compensation plan and applicable laws.

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/sivanssingh/soul-mlm.git
```

## 2. Enter Project

```bash
cd soul-mlm
```

## 3. Install Dependencies

For PHP / Laravel:

```bash
composer install
```

For Node.js:

```bash
npm install
```

For frontend:

```bash
npm install
```

Create:


```env
APP_NAME="Soul MLM"

QUEUE_CONNECTION=sync
```

# 🔐 Important Business & Compliance Note

MLM and network-marketing systems can be subject to financial, consumer-protection, direct-selling, tax, KYC/AML, advertising, and other regulations depending on the jurisdiction and business model.

This software is a **technology platform**.

Before launching a real-money MLM operation, the business owner should obtain appropriate legal, tax, compliance, and regulatory advice and ensure that:

- The compensation plan is lawful.
- Products/services are genuine where required.
- Marketing claims are accurate.
- KYC/AML requirements are followed where applicable.
